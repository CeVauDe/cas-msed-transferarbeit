
=== Systemarchitektur

<<#image-methoden-poc-overview>> zeigt den High-Level Systemarchitektur. Das System besteht im Wesentlichen aus drei Komponenten: dem Chatbot mit User Interface, LLM-Client und MCP-Client, dem MCP Server und dem Large Language Model. Der Chatbot und der MCP-Server werden in Python selbst implementiert, das LLM wird über eine API, hier von OpenAI, verwendet. Das Python-Ökosystem für künstliche Intelligenz ist sehr ausgereift und wird aktiv weiterentwickelt cite:[nguyen_machine_2019]. Ausserdem bietet es sämtliche notwendingen Software Development Kits (SDK). Auch für die Applikation wird Python genutzt, weil SDKs und die etablierte Toolchain schnell verfügbar sind. Sie wurde mit Hilfe von künstlicher Intelligenz erstellt.

Der Chatbot sowie der MCP-Server sind eigenständige Services, die über eine streamable HTTP-Schnittstelle kommunizieren. Beide sind als Docker-Container konstruiert und mittels Docker Compose orchestriert.

  rectangle "OpenAI API" <<external service>> {

  rectangle "Chatbot Service" <<component>> {
    port "HTTP" as http_in
    component "Web UI" as webui
    component "Agent" as agent
    component "MCP Client" as client

    http_in -right-> webui
    webui -right-> agent : "User Input"
    agent -right-> client : "Tool Calls"
  }

  rectangle "MCP Server" <<component>> {
    port "MCP\nstreamable HTTP" as mcp_port
    component "Tool Handler" as tool
    component "Glossar" as glossar
    component "Pandas Engine" as pandas

    mcp_port -right-> tool
    mcp_port -down-> glossar
    tool -right-> pandas : "Filter & Query"
  }

  database "Parquet Files" as data

  client -right-> mcp_port : "JSON-RPC"
  pandas -right-> data : "Read"
}

actor User
User -down-> http_in : "Web\nBrowser"
agent <-up-> openai_api : "HTTPS"
