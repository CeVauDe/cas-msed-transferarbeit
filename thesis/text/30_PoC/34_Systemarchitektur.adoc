@startuml
!theme plain
skinparam componentStyle rectangle
left to right direction

  rectangle "Chatbot Service" <<component>> as chatbot
  rectangle "MCP Server" <<component>> as mcp
  database "Parquet Files" as data

chatbot --> mcp : "MCP\n(JSON-RPC)"

Im nachfolgenden <<ergebnisse-poc-sequenzdiagram,Sequenzdiagram>> ist die Verarbeitungsloop der Beispielfrage `Wie hat sich der Marktanteil von SRF 1 in der DS von 2019 bis 2021 entwickelt?` dargestellt.

[[fig-agent-loop,Abbildung: Agent-Loop]]
.Sequenzdiagramm des agentenbasierten Verarbeitungsloops (Beispielfrage)
[plantuml, agent-loop, svg]
....
@startuml
!theme plain
skinparam sequenceMessageAlign center
skinparam responseMessageBelowArrow true

actor Benutzer
participant "Chatbot" as Chatbot
participant "MCP Server" as MCPServer
participant "OpenAI API" as OpenAI

Benutzer -> Chatbot: Benutzerfrage
activate Chatbot

== Initialisierung ==

Chatbot -> MCPServer: list_tools()
MCPServer --> Chatbot: Tool-Definitionen

Chatbot -> MCPServer: list_resources()\n+ read_resource()
MCPServer --> Chatbot: Glossar

== Tool-Runde (max. 15×) ==

Chatbot -> OpenAI: chat.completions.create()\n(System-Prompt + Glossar\n+ Benutzerfrage + Tools)
activate OpenAI
OpenAI --> Chatbot: tool_calls
deactivate OpenAI

Chatbot -> MCPServer: call_tool("abfrage_jahresbericht", …)
activate MCPServer
MCPServer --> Chatbot: Tool-Ergebnis\n(Markdown-Tabelle)
deactivate MCPServer

== Antwort ==

Chatbot -> OpenAI: chat.completions.create()\n(Nachrichten + Tool-Ergebnis)
activate OpenAI
OpenAI --> Chatbot: Textantwort
deactivate OpenAI

Chatbot --> Benutzer: Antwort
deactivate Chatbot

@enduml
....
