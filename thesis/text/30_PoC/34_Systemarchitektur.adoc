Im nachfolgenden <<ergebnisse-poc-sequenzdiagram,Sequenzdiagram>> ist die Verarbeitungsloop der Beispielfrage `"Wie hat sich der Marktanteil von SRF 1 in der DS von 2019 bis 2021 entwickelt?"` dargestellt.

.Sequenzdiagramm des agentenbasierten Verarbeitungsloops (Beispielfrage)
[plantuml, agent-loop, svg]
....
@startuml
!theme plain
skinparam sequenceMessageAlign center
skinparam responseMessageBelowArrow true

actor Benutzer
participant "Gradio\nChatInterface" as Gradio
participant "OpenAI Agent" as LLM
participant "MCP Client" as MCPClient
participant "MCP Server v2" as MCPServer

Benutzer -> Gradio: "Wie hat sich der Marktanteil von\nSRF 1 in der DS von 2019 bis 2021 entwickelt?"
activate Gradio

Gradio -> MCPClient: Neue MCP-Session öffnen
activate MCPClient

MCPClient -> MCPServer: list_resources()
MCPServer --> MCPClient: [glossar]

MCPClient -> MCPServer: read_resource("glossar")
MCPServer --> MCPClient: Glossar-Text\n(Fachbegriffe:\nMarktanteil, Rating, ...)

MCPClient -> MCPServer: list_tools()
MCPServer --> MCPClient: [abfrage_jahresbericht]

MCPClient --> Gradio: Tools + Glossar

Gradio -> LLM: System-Prompt + Glossar +\nNachricht + Tool-Definitionen
activate LLM

== Tool-Runde 1 ==

LLM -> LLM: Analysiere Anfrage:\nFilter: sender=[SRF 1], region=[Deutschschweiz],\njahr=[2019,2020,2021], kenngrösse=[Marktanteil in %]\nPivot: zeilen=Jahr

LLM -> MCPClient: tool_call: abfrage_jahresbericht(\n  sender=["SRF 1"],\n  region=["Deutschschweiz"],\n  jahr=[2019,2020,2021],\n  kenngrösse=["Marktanteil in %"],\n  zeitschiene=["Ganzer Tag"],\n  zeilen="Jahr",\n  spalten=["Jahr","Wert"])

MCPClient -> MCPServer: abfrage_jahresbericht
activate MCPServer

MCPServer -> MCPServer: Pandas DataFrame filtern:\n- Jahr in [2019,2020,2021]\n- Region = Deutschschweiz\n- Sender = SRF 1\n- Kenngrösse = Marktanteil in %

MCPServer --> MCPClient: Tool-Ergebnis (Markdown-Tabelle)
deactivate MCPServer

MCPClient --> LLM: Tool-Ergebnis (Markdown-Tabelle)

== Analyse & Antwort ==

LLM -> LLM: Daten vorhanden? \nKeine weiteren tool_calls nötig? \nAntwort formulieren

LLM -> Gradio: LLM formulierte Antwort

deactivate LLM
deactivate MCPClient

Gradio -> Benutzer: Antwort anzeigen
deactivate Gradio

@enduml
