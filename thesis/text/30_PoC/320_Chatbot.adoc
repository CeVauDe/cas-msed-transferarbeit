
=== Chatbot
Der Chatbot implementiert einen agentenbasierten Verarbeitungsloop mit den LLM Modellen `gpt-4o-mini` cite:[llmGpt4oMini] oder `gpt-5-mini` cite:[llmGpt5Mini] von OpenAI. Um aufwendiges Sessionhandling zu verhindern und die Komplexität zu reduzieren, wird pro Nachricht eine neue MCP-Session genutzt. Dies hat den Vorteil, dass der Kontext zeit- und serverunabhängig ist. Der Kontext ist immer gültig, auch bei Abbrüchen der Verbindung. Bei zwischenzeitlichen Serveraktualisierungen können zukünftige Nachrichten von potenziell neuen Tools oder Funktionen profitieren. Der Agent kann bis zu 15 Tool-Runden durchlaufen, bevor er eine finale Antwort produziert. Beim Erreichen der maximalen Runden wird abgebrochen, um Endlosschleifen zu verhindern. Das User Interface ist ein Standard Chat Interface von Gradio cite:[gradio].
