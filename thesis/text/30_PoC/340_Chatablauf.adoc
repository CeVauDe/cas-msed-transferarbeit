
=== Chatsequenz

In <<#sequenzdiagramm-agent-loop>> ist die Verarbeitungsloop einer Chatantwort als Sequenzdiagramm dargestellt. Mit dem Absenden der Benutzerfrage initialisiert der Chatbot den MCP-Client und erstellt eine MCP-Session mit dem MCP-Server. Dabei werden die verfügbaren Tools und Ressourcen geladen. In der Tool-Runde werden die vorhandenen Informationen wie System-Prompt, Benutzerfrage, Tool-Definition und Ressourcen an das LLM übermittelt. Das LLM verarbeitet die Informationen und erstellt bei Bedarf Tool-Aufrufe um Daten abzufragen. Diese werden anschliessend vom Chatbot über den MCP-Clienten ausgeführt und die Ergebnisse in der nächsten Tool-Runde an das LLM übermittelt. Es werden so viele Tool-Runden durchgeführt, bis das LLM keine Tool-Aufrufe mehr erstellt. Der letzte LLM-Aufruf liefert dann die Antwort, die dem Benutzer im Chatinterface angezeigt wird.

[#sequenzdiagramm-agent-loop]
.Sequenzdiagramm des agentenbasierten Verarbeitungsloops
[plantuml, agent-loop, svg]
....
@startuml
!theme plain
skinparam sequenceMessageAlign center
skinparam responseMessageBelowArrow true

actor Benutzer
participant "Chatbot\n(MCP-Client &\nLLM-Client)" as Chatbot
participant "MCP-Server" as MCPServer
participant "OpenAI API (LLM)" as OpenAI

Benutzer -> Chatbot: Benutzerfrage
activate Chatbot

== Initialisierung ==

Chatbot -> MCPServer: list_tools()
MCPServer --> Chatbot: Tool-Definitionen

Chatbot -> MCPServer: list_resources()\n+ read_resource()
MCPServer --> Chatbot: Glossar

== Tool-Runde (max. 15×) ==

Chatbot -> OpenAI: chat.completions.create()\n(Benutzerfrage + System-Prompt\n+ Tool-Definitionen + Ressourcen)
activate OpenAI
OpenAI --> Chatbot: Auszuführende Tool-Aufrufe
deactivate OpenAI

Chatbot -> MCPServer: call_tool("abfrage_jahresbericht", …)
activate MCPServer
MCPServer --> Chatbot: Tool-Ergebnis\n(Markdown-Tabelle)
deactivate MCPServer

== Antwort ==

Chatbot -> OpenAI: chat.completions.create()\n(Nachrichten + Tool-Ergebnis)
activate OpenAI
OpenAI --> Chatbot: Antwort
deactivate OpenAI

Chatbot --> Benutzer: Antwort
deactivate Chatbot

@enduml
....
