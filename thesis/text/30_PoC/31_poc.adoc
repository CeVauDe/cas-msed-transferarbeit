

=== Datenaufbereitung

Die zu verwendenden Daten stehen als 24 Exceltabellen zur Verfügung. Für jedes Jahr, jede Region und SRF/andere gibt es eine Tabelle im `wide` Format. Das bedeutet, jeder Zeitschienenwert hat eine Zeile mit allen Kombinationen aus Sender und Metrik in eigenen Spalten. Für die Filterung nach spezifischen Kombinationen ist das `long` Format nötig, in dem jede Zeile aus der `wide` Tabelle eine eigene Zeile bekommt.

Zusätzlich werden die Daten so aufbereitet, dass sie besser von einem LLM verarbeitet werden können. Zum Beispiel werden Regionenkürzel wie `DS` zu `Deutschschweiz` und Namen der Kenngrössen ausgeschrieben. Ziel ist der sonst notwendige Mapping-Schritt im Verarbeitungsauftrag des LLMs überspringen zu können und so Missverständnisse zu reduzieren.

Als Output der Datenaufbereitung wird eine `.parquet`-Datei geschrieben, die dem MCP-Server bereitstellt wird.

Der MCP-Server stellt ein Werkzeug (`Tool`) und eine Ressource (`Resource`) bereit:

* **Tool `abfrage_jahresbericht`**: Strukturierte Datenabfrage mit Filterung nach Jahr, Region, Zeitschiene, Kenngrösse und Sender. Unterstützt Pivot-Tabellen und Sortierung. Gibt Markdown-Tabellen zurück.

* **Ressource `glossar`**: Glossar mit Fachbegriffen der TV-Forschung (Marktanteil, Rating, Nettoreichweite, Sehdauer, etc.).

==== Datenabfrage

#TODO: add url to pandas website?#
Das `abfrage_jahresbericht` Werkzeug nutzt pandas für die Datenverarbeitung:

1. **Filterung**: Die `.parquet`-Datei wird als pandas DataFrame geladen. Filter werden direkt auf den DataFrame angewendet (z.B. `df[df["Jahr"].isin([2019,2020,2021])]`).

2. **Pivot-Tabellen**: Bei Vergleichen über mehrere Dimensionen (z.B. mehrere Jahre oder Sender) werden Pivot-Tabellen erstellt (`pivot_table` mit `index` und `columns`).

3. **Sortierung**: Ergebnisse können nach beliebigen Spalten aufsteigend oder absteigend sortiert werden (`sort_values`).

4. **Ausgabe**: Das Ergebnis wird als Markdown-Tabelle formatiert und zurückgegeben (`to_markdown`).

Die Glossar-Ressource wird dem MCP-Client als statischer Markdown-Text bereitgestellt und enthält Definitionen für alle wichtigen Kennzahlen der TV-Forschung.
