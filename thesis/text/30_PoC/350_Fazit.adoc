
=== Fazit
Es wird gezeigt, dass mit einfachen Mitteln ein Chatbot erstellt werden kann, der über einen MCP-Server Daten abfragen und dann in einer Antwort korrekt wiedergeben kann. Der Unterschied zwischen den MCP-Server Versionen eins und zwei macht deutlich, dass ein einfacher Aufbau wesentlich robuster funktioniert und die Antworten schneller generiert werden können, da weniger Tool-Runden gemacht werden müssen. Den Fokus bereits in der Datenaufbereitung auf einfache Verständlichkeit der Daten zu legen hilft auch dem LLM, die richtigen Daten abzufragen und zu einer verständlichen Antwort zu formulieren.

Der Chatbot kann lokal mittels Docker Compose aus dem `/poc`-Verzeichnis cite:[githubRepoTransferarbeit] heraus ausgeführt werden. Dafür ist lediglich ein OpenAI API Key erforderlich, der in der `/poc/.env`-Datei eingetragen sein muss. Alle weiteren erforderlichen Komponenten und Daten werden bei Bedarf automatisch geladen oder sind bereits in den Docker Images enthalten.
